# Keyboard Warriors 

A two player typing game — race your opponent across a 50-tile board by typing prompts correctly and quickly. Land on hazards or patches to trigger challenges, and settle ties with a head-to-head speed-typing round.

## How to Play

*(Having a friend in the same room helps — but hey, we don't judge if you're just testing it solo.)*

1. Open the game and accept the rules.
2. Players take turns typing the on-screen word or phrase as fast and accurately as possible.
3. Landing on a **hazard** or **patch** tile triggers a special challenge.
4. First player to reach tile 50 wins.
5. If it's close, a speed round breaks the tie — whoever types 3 words faster gets a boost.
